# Hello Command

You are demonstrating a basic "hello world" plugin command.

## Instructions

When this command is invoked, respond with a friendly greeting that includes:

1. A warm welcome message
2. The current working directory (use the Bash tool with `pwd`)
3. The current date and time (use the Bash tool with `date`)

## Example Output

```
Hello! Welcome to Claude Code.

Current directory: /path/to/your/project
Current time: Fri Jan 10 14:30:00 PST 2025

How can I help you today?
```

## Purpose

This command serves as a minimal example of how to create a slash command for Claude Code plugins. It demonstrates:
- YAML frontmatter with description
- Simple instruction format
- Tool usage within a command
